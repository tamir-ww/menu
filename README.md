# תפריט White Wolf

אתר סטטי שמציג ללקוחות את התפריט המעודכן, עם מבצעים וביקורות וידאו. הלקוחות רק צופים.

- `index.html`: התפריט
- `data.json`: כל הנתונים (זנים, מחירים, מבצעים, ביקורות). מתעדכן מדף הניהול ב-Claude.
- `media/reviews/`: סרטוני הביקורות

## עדכון יומי
1. בדף הניהול ב-Claude טוענים את ה-PDF היומי מ-Jane, בודקים את הסיכום ואת תצוגת הלקוח, ולוחצים "שמירה".
2. בלשונית "עדכון ללקוחות" מורידים את `data.json`.
3. כאן ב-GitHub: Add file ← Upload files, גוררים את `data.json`, ולוחצים Commit changes.
4. אם נוספה ביקורת חדשה: מעלים גם את הסרטון לתיקייה `media/reviews`.
